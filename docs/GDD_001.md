# Project 001 设计备忘录（GDD v0.1）

> **方向定位**：赛博朋克黑市当铺模拟经营（参考 *Probably Stolen*），采用 **3D 空间沉浸 + 2D 精细交互穿插** 的混合美术与玩法结构。

## 1. 核心玩家体验循环 (Core Loop)
1. **3D 备货与开店 (`PREP -> OPEN`)**：
   - 在 3D 店铺内检查货架陈列、信用点余额与房租倒计时。
   - 后期可扩展：在 3D 工作站摆放/升级机器（如合成台、净水器、改码器）。
2. **2D 纸片人顾客进店（3D 队列 + 2D 角色表现）**：
   - 各派系顾客（拾荒者、公司职员、辛迪加跑腿、暗访稽查员）走到 3D 柜台前。
   - 玩家可直接观察顾客对话与可疑神态。
3. **3D -> 2D 鉴定与讨价还价穿插 (`Appraisal Workbench 2D`)**：
   - 点击柜台商品或按 `Tab` 切入 **2D 俯视工作台**。
   - 用鼠标拖动 **2D UV/X光扫描框**，揭露隐藏特征：
     - 磨掉的序列号 / 血迹 / Syndicate 水印（说明大概率是赃物 `STOLEN`）
     - CorpSec 微型追踪信标（买下会大幅抬高 `Heat`，除非后续洗白或转卖黑市）
   - 调整报价滑块压价或让利，决定 **收购 / 拒绝 / 举报给 CorpSec**。
4. **日结与房租压力 (`CLOSING`)**：
   - 每日结算营收；每 3 天需缴纳一次递增的店铺租金。
   - 终极原型目标：攒够买断资金彻底买下店铺，或在高 `Heat` 稽查中生存下来。

## 2. 为什么采用「3D + 2D 穿插」
- **3D 的优势**：营造窄小阴暗的赛博底层空间压迫感、霓虹体积光、柜台与货架的真实空间调度。
- **2D 的优势**：
  1. 人物立绘/骨骼动画在 2D 中表达微表情、可疑眼神、服装细节成本远低于高精度 3D 建模。
  2. 物品鉴定、拆解、改码、地图黑市交易等需要高信息密度与精确拖拽的操作，2D 工作台手感最好。
  3. 当玩家从 3D 柜台「俯身」切入 2D 鉴定桌，能形成强烈的“收银台视角 <-> 专业操作台视角”切换仪式感。
